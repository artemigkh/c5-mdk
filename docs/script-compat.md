## Notes from the render review (one PNG per script, standard size, seed 1)

* No all-ocean maps, no starts in water (validated), every non-WorldBuilder script places rivers, resources and (where the script allows them) natural wonders.
* `exp1:Tilted_Axis`: every water plot in the northern half is ice. By design: its `AddIceAtPlot` override sets ice on every plot with `iY >= iH / 2`.
* `vp:Skirmish`: no water at all with the default 'Rivers' water setting (option 2 = 1); the validator only requires coast terrain when the map has water.
* `vp:Ring`, `assets:Ring`: city-states are forced into the small polar centre; at standard size VP discards most of them for crowding (2 of 16 placed). Script behaviour, same in game.
* `vp:Four_Corners`, `vp:West_vs_East`: 15 of 16 city-states placed (crowding), not a harness issue.
* `vp:Amazon_XP`, `vp:Script_Random_China`: no natural wonders by design ("No Natural Wonders available on this script").
* Arborea/Rainforest/Sandstorm (exp1, vp-emp, dlc-sp1) produce identical plot types for the same seed: they share the same plot-type generator code; only terrain/features/resources differ.
* Team scripts (`North_vs_South`, `West_vs_East`, `Hemispheres`, `Four_Corners`, `Europe`, `Frontier`, `Ring`, `Skirmish`, `Large_Islands`) run in team mode with `--teams 2` (`--teams 4` for Four_Corners); team 0 and team 1 start on opposite halves as intended.

## Flags worth knowing

* `--teams N` groups the major civs round-robin into N teams (needed for Hemispheres).
* `--option IDX=VALUE` now warns on stderr when the script has no option IDX or VALUE is outside its range (the value is still passed through, as the game would).
* `--list-options` resolves option names from the mods' en_US text XML as well as the localization cache (the option names of `vp:Communitu_79a` were raw TXT_KEYs before).
* WorldBuilder hybrids (`WB_Script_*`, or scripts that call `Map.LoadMap` / mention `.Civ5Map`) are not run: they read plot types from a map file the exe loads before the script, so headless they would see an all-ocean map.
